# Вероятность с анимациями

Интерактивный модуль для 10 класса по разделу 10.1С «Элементы комбинаторики и теории вероятностей».

- Уроки 57–60, цель 10.4.3.1 — сложение и умножение вероятностей.
- Уроки 61–64, цель 10.4.3.2 — условная вероятность.
- Уроки 183–187 — повторение этих целей.

## Запуск

Распакуйте архив и откройте `index.html` в браузере. Сайт работает офлайн. Для публикации как статического сайта загрузите содержимое папки с сохранением структуры файлов. Главный проект может ссылаться на главную страницу модуля или на конкретную тему по хешу, например `#/conditional`.

Учебные задачи и разборы находятся в `lessons.js`. Интерактивы, тренажёр и навигация — в `app.js`.
